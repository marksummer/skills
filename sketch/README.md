# Sketch

Explore an interface idea with a quick, interactive sketch. Start with one element, then expand to a screen or flow when you need more context.

## Install

Follow the [installation steps](../README.md#install) and choose Sketch.

Interactive previews need the Visualize plugin in Codex, installed separately. Without it, the skill provides a layout outline.

## Use

```text
Use $sketch to explore batch reminder entry: one editable row per reminder,
with adding, removing, and pasting multiple lines.
```

Describe the element and the decision you want to make. Add screenshots or product context if you have them. Ask for a comparison, full screen, or flow when that is the scope you need.

## What you get

A sketch with readable sample content and working local interactions. Revisions keep the choices you have already made. Actions are simulated; a sketch does not save data to your product or publish it.

## Example

The [reminder-entry demo](https://raw.githubusercontent.com/marksummer/skills/main/examples/batch-reminders.html) explores editable rows, keyboard entry, and multiline paste. Download it and open it in a browser.
