# Tune Motion

Try a component's animation in chat before implementing it. Adjust easing, springs, and the motion curve while the preview runs.

## Install

Follow the [installation steps](../README.md#install) and choose Tune Motion.

Requires the Visualize plugin in Codex, installed separately, and Python 3 for the preview generator.

## Use

```text
Use $tune-motion to show the accent picker expanding and collapsing
so I can tune its animation.
```

Describe the component and what changes between its resting and active states. You can also supply its source so the preview matches its shape and behavior.

## What you get

One component preview with playback controls, practical presets, and editable values. Copy exports the full specification, including precise parameters, property mappings, and reference code.

Ask to apply the chosen motion when you are ready. If the saved values are unavailable, paste the copied specification. Creating the preview does not change or publish your product.
